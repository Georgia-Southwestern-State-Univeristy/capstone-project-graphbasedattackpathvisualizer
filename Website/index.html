How to use this site

  1. Toggle mitigations in the left panel to simulate defenses.
  2. Click Compute Path to calculate the easiest attack path to the database.
  3. Click nodes/edges to inspect what they represent and why an attack step matters.
  4. Use Reload Graph if you want to reset the visualization.
  5. Click Clear to remove highlighting and return to the default view.
Tip

The highlighted path represents the lowest “difficulty” route. Turning on defenses should increase the cost or break paths.

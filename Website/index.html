Configure Your Business

i
Configure Your Environment: Select which systems your business uses. These choices determine how your network is modeled and which attack paths are possible.

External Access & Perimeter

ⓘ More info

A VPN lets employees securely connect to your company’s network from outside the office, such as from home or while traveling. It creates a protected connection so internal systems can be accessed safely over the internet. Examples include Cisco AnyConnect, OpenVPN, NordLayer, and other company-issued remote access tools.

ⓘ More info

This refers to anything your business hosts that is accessible to the public over the internet, such as a website, customer portal, or online service. Attackers often target these because they are exposed externally. Examples include company websites, login portals, online stores, and booking systems.

ⓘ More info

If your office provides Wi-Fi for employees or guests, you are using a wireless network. These networks can introduce security risks if not properly secured or segmented. Examples include office Wi-Fi routers, guest networks, and enterprise wireless systems like Ubiquiti or Cisco.

ⓘ More info

A firewall monitors and controls traffic entering and leaving your network to block unauthorized access. Most businesses have one, even if it’s built into a router or provided by a cloud service. Examples include Fortinet, Palo Alto, Cisco ASA, built-in router firewall, and cloud firewalls in AWS or Azure.

Identity, Email & Cloud Services

ⓘ More info

An identity provider allows employees to log in once and access multiple systems without re-entering credentials. It centralizes authentication and is commonly used in modern businesses. Examples include Okta, Microsoft Azure AD, Google Workspace login, and OneLogin.

ⓘ More info

If your organization uses email accounts tied to your business domain, you have a business email system. Email is one of the most common entry points for attacks like phishing. Examples include Microsoft Outlook/Exchange, Gmail for business, and hosted email servers.

ⓘ More info

SaaS applications are tools hosted by third-party providers that your business accesses through the internet. These are very common and often integrate with your login system. Examples include Google Workspace, Microsoft 365, Salesforce, Slack, and Dropbox.

ⓘ More info

Mobile Device Management, or MDM, lets companies monitor, secure, and control employee laptops and mobile devices. This is common in organizations that issue company devices. Examples include Microsoft Intune, Jamf, and VMware Workspace ONE.

Internal Infrastructure

ⓘ More info

A file server is a central place where employees store and access shared documents. It can be on-site or in the cloud but is used for internal collaboration. Examples include network shared drives, Windows file servers, NAS devices, and shared folders.

ⓘ More info

A domain controller manages user accounts, passwords, and permissions across your organization. If employees log into a company network account, this likely exists. Examples include Active Directory and Windows Server domain environments.

ⓘ More info

These are systems only accessible from inside your organization, not the public internet. They often support operations like inventory, dashboards, or internal workflows. Examples include internal dashboards, company tools, and intranet apps.

ⓘ More info

A DNS server helps devices find each other on the network using names instead of IP addresses. Many businesses use internal DNS without realizing it. Examples include Windows DNS, router-based DNS, and enterprise DNS services.

ⓘ More info

A backup system stores copies of important data so it can be recovered after data loss, ransomware, or system failure. Most businesses use some form of backup, even if automated. Examples include cloud backups, external drives, backup servers, and services like Veeam or Carbonite.

Business Systems

ⓘ More info

An HR system stores employee records, payroll data, and personal information. These systems often contain sensitive data and are high-value targets. Examples include Workday, ADP, and BambooHR.

ⓘ More info

A finance system handles accounting, payments, and financial records. These systems are critical and often targeted for fraud or data theft. Examples include QuickBooks, SAP, Oracle Financials, and payroll systems.

How to Use GBAV

  1. Toggle mitigations in the left panel to simulate defenses.
  2. Click Compute Path to calculate the easiest attack path to the database.
  3. Click nodes/edges to inspect what they represent and why an attack step matters.
  4. Use Reload Graph if you want to reset the visualization.
  5. Click Clear to remove highlighting and return to the default view.
Tip

The highlighted path represents the lowest “difficulty” route. Turning on defenses should increase the cost or break paths.
